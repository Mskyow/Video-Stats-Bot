# Как применить миграции в Supabase вручную

В проекте две миграции, которые нужно применить в Supabase Dashboard → SQL Editor, если их ещё не применяли.

---

## Миграция 007: колонка screenshots_mode (таблица users)

Если при нажатии кнопок «2 скриншота» / «3 скриншота» бот пишет **«Не удалось сохранить режим»**, в таблице `users` нет колонки `screenshots_mode`.

## Пошагово

1. Открой **Supabase Dashboard**: https://supabase.com/dashboard  
   Войди в аккаунт и выбери проект, к которому подключается бот (тот же, что в `.env`: `SUPABASE_URL`).

2. В левом меню выбери **SQL Editor** (иконка «</>» или пункт «SQL Editor»).

3. Нажми **New query** (или «+ New query»), чтобы открыть пустое окно для SQL.

4. Скопируй и вставь **весь** код ниже в это окно:

```sql
-- 007: Режим скриншотов: 2 (пара) или 3 скриншота на одно видео
ALTER TABLE users ADD COLUMN IF NOT EXISTS screenshots_mode TEXT NOT NULL DEFAULT '2';

DO $$ BEGIN
    ALTER TABLE users ADD CONSTRAINT chk_users_screenshots_mode
        CHECK (screenshots_mode IN ('2', '3'));
EXCEPTION WHEN duplicate_object THEN NULL;
END $$;

COMMENT ON COLUMN users.screenshots_mode IS '2 = пара скриншотов на видео (Overview + Retention), 3 = три скриншота на видео';
```

5. Нажми **Run** (или Ctrl+Enter / Cmd+Enter).

6. Внизу должно появиться сообщение об успешном выполнении (например, «Success. No rows returned»). Ошибок быть не должно.

7. Готово. Перезапускать бота не нужно — при следующем нажатии «2 скриншота» или «3 скриншота» режим будет сохраняться, сообщение «Не удалось сохранить режим» исчезнет.

Если колонка уже есть (например, миграция уже применялась), выполнение скрипта не сломает базу: `ADD COLUMN IF NOT EXISTS` и блок с `EXCEPTION WHEN duplicate_object` это учитывают.

## Миграция 008: колонки для режима «3 скриншота» (таблица videos)

Если при отправке **трёх скриншотов** бот обрабатывает видео, но пишет **«Ошибка сохранения в базу данных»** и в Google таблицу ничего не экспортируется, в таблице `videos` нет колонок для метрики «удержание после смыслового конца» (3-й скриншот). Их нужно добавить.

**Куда вставлять:** тот же Supabase Dashboard → SQL Editor → New query.

**Код для вставки и Run:**

```sql
-- 008: Режим 3 скриншота — отдельные колонки для аналитики
ALTER TABLE videos ADD COLUMN IF NOT EXISTS end_retention_second INTEGER;
ALTER TABLE videos ADD COLUMN IF NOT EXISTS end_retention_pct NUMERIC;

COMMENT ON COLUMN videos.end_retention_second IS 'Second at retention-after-core (3rd screenshot); integer, e.g. 6 for 0:06';
COMMENT ON COLUMN videos.end_retention_pct IS 'Retention percentage at that second (0-100); from 3rd screenshot Retention Rate';
```

После успешного выполнения («Success. No rows returned») сохранение при трёх скриншотах и экспорт в Google таблицу должны заработать.
