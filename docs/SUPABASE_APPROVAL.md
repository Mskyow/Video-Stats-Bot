# Как одобрить пользователей в Supabase

Когда кто-то впервые пишет боту, он **автоматически** добавляется в таблицу `users` со статусом `pending`. Доступ к боту у него будет только после того, как ты поменяешь статус на `approved`.

## Пошагово

1. Открой **Supabase Dashboard**: https://supabase.com/dashboard  
2. Выбери свой проект (Video Stats Bot).
3. В левом меню нажми **Table Editor** (иконка таблицы).
4. В списке таблиц выбери **`users`**.
5. В таблице появятся все пользователи. Обрати внимание на колонки:
   - **id** — Telegram user_id
   - **username** — @username из Telegram
   - **first_name**, **last_name** — имя и фамилия
   - **status** — `pending` / `approved` / `rejected`

6. Чтобы **одобрить** пользователя:
   - Найди строку с нужным пользователем (status = `pending`).
   - Кликни по ячейке в колонке **status**.
   - Если видишь **выпадающий список** — выбери **`approved`**.
   - Если список не показывается — **введи вручную** слово `approved` в ячейку и нажми Save.
   - Сохрани (Enter или кнопка сохранения).

7. После этого пользователь сможет пользоваться ботом (отправлять скриншоты и получать анализ).

## Отклонить пользователя

Вместо `approved` выбери **`rejected`**. Пользователь будет видеть сообщение об отказе и не сможет использовать бота.

## Уведомления в Telegram (опционально)

Чтобы бот **присылал тебе в Telegram** сообщение о каждом новом пользователе:

1. Узнай свой Telegram ID (например, напиши боту [@userinfobot](https://t.me/userinfobot) — он пришлёт твой ID).
2. В файле **`.env`** добавь строку:
   ```env
   ADMIN_USER_ID=123456789
   ```
   (подставь свой ID вместо `123456789`).
3. Перезапусти бота.

После этого при каждой новой заявке ты получишь сообщение с данными пользователя и напоминанием зайти в Supabase и поставить `approved`.

---

## Выпадающий список вместо ввода вручную (опционально)

Если хочешь, чтобы в ячейке **status** был именно выпадающий список (pending / approved / rejected), выполни в **SQL Editor** содержимое файла `supabase/migrations/003_status_enum_dropdown.sql`. После этого тип колонки станет ENUM и в Table Editor появится выбор из трёх значений.
