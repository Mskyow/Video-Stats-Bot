# AI Methodology для Day Summary - Как работает анализ

## 🎯 Проблема (ДО улучшения)

### Старый промпт (базовый):
```
Ты — Senior Growth Analyst.
Вот данные:
- 5 видео
- Short hooks: avg score 8.4, retention 76%
- Long hooks: avg score 3.5, retention 42%

Проанализируй и дай рекомендации.
```

**Проблемы:**
- ❌ AI не знает что такое "хороший" retention (76% - это много или мало?)
- ❌ Нет контекста бенчмарков (какие пороги для SCALE/KILL?)
- ❌ AI "угадывает" из общих знаний, не использует твою методологию
- ❌ Рекомендации общие: "Улучшай хуки" вместо конкретных советов

### Что AI делал:
```
AI думает: "76% звучит неплохо, наверное это хорошо"
AI думает: "42% звучит средне, наверное это так себе"
→ Выдаёт общие советы на основе догадок
```

## ✅ Решение (ПОСЛЕ улучшения)

### Новый промпт (с методологией):

```
Ты — Senior Growth Analyst, эксперт по short-form контенту.
Используй СТРОГУЮ МЕТОДОЛОГИЮ АНАЛИЗА:

🎯 TIER 1 - GATEKEEPER METRICS:
• Hook (3s retention):
  - FAIL: < 58%
  - GOOD: 60-70%
  - SCALE/VIRAL: > 70%

📈 TIER 2 - GROWTH ENGINE:
• Share rate (high volume):
  - OK: 0.5-1%
  - VIRAL: > 1.5%

🚨 EXPERT HEURISTICS:
• Platinum Retention Trap: hook > 75% BUT completion < 30%
• Gold Format Candidate: views > 3x avg + share > 1.5%

🎭 DECISION TREE:
1. KILL: retention < 58% → хук провалился
2. SCALE: retention > 70% + share > 1.5% → масштабировать

Теперь проанализируй данные через призму этой методологии:
- Short hooks: retention 76% (ВЫШЕ порога 70% = SCALE!)
- Long hooks: retention 42% (НИЖЕ порога 58% = FAIL!)
```

### Что AI теперь делает:
```
AI: "76% retention > 70% (SCALE порог) → это вирусный потенциал"
AI: "42% retention < 58% (FAIL порог) → хук провалился"
AI: "Share rate 2.1% > 1.5% → вирусный контент, масштабировать"
→ Выдаёт КОНКРЕТНЫЕ советы на основе ТВОЕЙ методологии
```

## 📋 Полная методология в промпте

### 1. TIER 1 - Gatekeeper Metrics (из benchmarks.py)

**Hook (3s retention):**
- FAIL: < 58%
- BORDERLINE: 58-60%
- GOOD: 60-70%
- SCALE/VIRAL: > 70%

**Completion Rate (зависит от длины):**
- Ultra-short (0-10s): FAIL < 60%, EXCELLENT > 90%
- Standard (11-20s): FAIL < 40%, EXCELLENT > 65%
- Long (21s+): FAIL < 30%, EXCELLENT > 55%

**Avg Watch Time %:**
- Ultra-short: FAIL < 75%, VIRAL ≥ 100% (looping)
- Standard: FAIL < 60%, VIRAL > 80%
- Long: FAIL < 30%, EXCELLENT > 55%

### 2. TIER 2 - Growth Engine

**High volume (3000+ views):**
- Share rate: OK 0.5-1%, VIRAL > 1.5% 🔥
- Save rate: OK 0.5-1%, HIGH VALUE > 1.5%
- Comment rate: OK 0.1-0.4%, EXCELLENT > 0.5%

**Low volume (cold phase):**
- Aggregated ER: FAIL < 6%, OK 6-10%, HIDDEN GEM > 10%

### 3. Expert Heuristics (паттерны)

**Platinum Retention Trap:**
- Hook 3s > 75% НО completion < 30%
- = Крутой хук, но слабое тело
- Рекомендация: фиксить body, не hook

**Failed Breakout:**
- Views < avg BUT ER high (share 2%+)
- = Алгоритм не подхватил, но контент сильный
- Рекомендация: репост в другое время, варианты хука

**Gold Format Candidate:**
- Views > 3x avg + share > 1.5%
- = Выигрышный формат
- Рекомендация: СРОЧНО масштабировать

**Hidden ER Gem:**
- Low views BUT ER > 10%
- = Алгоритм может протестить снова
- Рекомендация: подождать, не трогать

### 4. Decision Tree (приоритеты)

```
1. KILL: retention 3s < 58%
   → Хук провалился, переделать полностью

2. FIX: retention OK НО completion низкий
   → Хук работает, фиксить тело

3. SCALE: retention > 70% + share > 1.5%
   → Лить бюджет, масштабировать

4. HIDDEN GEM: low views НО ER > 10%
   → Подождать, может взлететь
```

```
Рекомендую делать больше коротких хуков."
```
❌ Общее, неконкретное

### AI анализ С методологией (новый):
```
<b>📊 Общая картина:</b>
2 видео с разными результатами. Средний retention 59% (borderline зона 58-60%).

<b>🎯 Что сработало:</b>
Видео с коротким хуком показало retention 76% (ВЫШЕ порога 70% = SCALE зона) и share rate 2.1% (ВЫШЕ порога 1.5% = вирусный потенциал). Это паттерн "Gold Format Candidate" - views выше среднего + высокий share rate. СРОЧНО масштабировать этот формат.

<b>⚠️ Проблемные зоны:</b>
Видео с длинным хуком: retention 42% (НИЖЕ критического порога 58% = FAIL). Хук не зацепил аудиторию в первые 3 секунды. Share rate 0.3% (НИЖЕ порога 0.5%) подтверждает отсутствие резонанса.

<b>💡 Рекомендации на завтра:</b>
• Делай больше видео с короткими хуками (1-10 слов) - они показали +81% к retention vs длинные
• Масштабируй формат успешного видео: повтори структуру хука и паттерн подачи
• Избегай длинных текстовых хуков (30+ слов) - 100% FAIL rate сегодня, порог не преодолён
```
✅ Конкретно, с цифрами, actionable

## 🎓 Как это работает технически

### 1. Агрегация данных (`_aggregate_videos_data`)

```python
    "long": {"count": 1, "avg_retention": 42.0}
```

### 2. Формирование промпта (`_build_summary_prompt`)
```python
prompt = f"""
МЕТОДОЛОГИЯ:
- Hook SCALE порог: > 70%
- Hook FAIL порог: < 58%

ДАННЫЕ:
- Short hooks: retention 76%
- Long hooks: retention 42%

Проанализируй используя методологию.
"""
```

### 3. AI анализ с контекстом
```
AI читает методологию → знает что 76% > 70% = SCALE
AI читает данные → видит что short hooks = 76%
AI делает вывод: short hooks в SCALE зоне
AI даёт рекомендацию: масштабировать short hooks
```

### 4. Парсинг и возврат
```python
summary = """
```
